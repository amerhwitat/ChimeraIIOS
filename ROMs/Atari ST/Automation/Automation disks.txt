Automation Compact Disk Catalog
A_001.ST - A_512.ST


NOTES:


EXPLANATION: This is an updated listing of all available Atari ST "compact disks" released by Automation. When I first found them, I was excited to find all the old games out there, but the inaccuracy of the list that accompanied them was deplorable. So, here is a 100% (or at least 99%) accurate list. I have gone through each and every one of these and tested them to some degree with STEEM Atari STE emulator.

DISK IMAGE SOURCES: All testing was done on images obtained from either ftp.megafile.com or ftp.mindbomb.com. The links on this page will download the disks from ftp://ftp.cs.tu-berlin.de/pub/atari/ so there may be some slight variations.

DEFECTIVE DISK IMAGES: Those images found to be defective have been annotated as "AVAILABLE IMAGE IS DAMAGED" or "AVAILABLE IMAGE IS POSSIBLY DAMAGED."

OFFENSIVE MATERIAL: Many of these disks contain offensive material, in both the menus and some of the games. Where I have found such content, I have marked either the game itself or the menu with an asterisk [*] . For those disk images for which the menu is obscene, the first line (directly below the image's filename) is marked with a lone asterisk. I have not caught all instances of profanity, sexual content, etc. -- there is most certainly some that I didn't notice, so caveat emptor.

UPDATES: If you find information on this listing which is inaccurate or incomplete, and certainly if you find/have good images of the disks I have marked as DAMAGED, please e-mail me, and I will be sure the list is updated and gets posted somewhere.

Enjoy!
