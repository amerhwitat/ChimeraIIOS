TOS Images

In order to correctly emulate an Atari ST, WinSTon requires the operating system from an original machine in file form. This is the Atari STs operating system (TOS) which can be thought of as the machines 'personality'. WinSTon has an emulated TOS 1.00 built-in allowing the emulator to run straight away. You can override this rom by selecting one of your own images. You can download other versions of the operating system from Internet sites such as The Little Green Desktop.

NOTE - WinSTon is compatible with all major versions of the ST TOS (1.00,1.02,1.04 and TOS 2.06). WinSTon will NOT work with any STe TOS ROMs, such as 1.06 and 1.62. These ROMs were designed for use only on an STe and as such will not work in a real STfm or WinSTon.
