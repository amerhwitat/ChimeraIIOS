Favourites

WinSTon allows you to customise this selection dialog to make it easier to run your favourite games. By default you will be presented with a list of games availble on a selection of disc images from crack groups. In order to run these images you will need to have the discs on your hard-drive. If you do not you may be able to download them from the Internet if WinSTon knows of a site where they can be obtained.
NOTE - If a game is listed in the Favourites dialog it does not mean that the game will run under WinSTon correctly, if at all. The WinSTon emulator is a 'work-in-progress' and I am working to improve compatibility. As new versions are released more and more games/applications will become playable.



Settings

The Favourites are setup to use the default 'Discs' and 'TosImages' directories which can be found where you installed WinSTon on to your hard-drive. Here you will see a number of sub-directories setup for your images to be copied into - 'Automation', 'DBug', 'Pompey', and 'Medway'. The dialog settings found on the Disc Images and TOS/GEM pages tell the favourites where to find these images - if you modify these to your own drive structure the favourites will also be updated. You will notice that the filenames used in the default file are the same as those found on The Little Green Desktop. Remember that you can always rename your files or directories to match that of the WinSTon file or change the file in a text editor. For more information on this see the Manually Editing The Favourites File page.
If you do not wish to use the default file and want to create your own you can simply remove the items in the dialog structure or delete the 'favourites.txt' file stored in the WinSTon directory.
NOTE - Due to the large number of game titles available some of the disc images listed in the default favourites file may be incorrect. These errors will be corrected for future versions.

Running Disc Images

Disc images are listed in the Favourites view as a folder structure similar to that of your hard-drive. You can click through the folders and scroll down to the disc of your choice and double-click on the name(or use the Run button) to insert the disc/s into the emulated drives and reset WinSTon.
Should WinSTon be unable to find the disc image it will bring up an error giving you the option of downloading the image from the Internet. This image can then be downloaded and saved to the correct place on your hard-drive to select again.
The default Favourites listing is customised to use the directory structure in the 'Discs' folder where you installed WinSTon. It also assumes that the filenames of the images match with its listings but does not need to know the format(.ST, .MSA or .ZIP) of the discs to run.
As you browse through the lists of discs WinSTon will scan each image in turn to find if the disc exists on your system. Any discs not found will be marked in the favourites listings by a red cross over the disc image icon.

Downloading Disc Images

WinSTon gives you the ability to download disc image files from the Internet with the help of The Little Green Desktop. You can do this by either selecting the 'Download' button after highlighting the game you wish from the default favourites listing or by trying to run an image which cannot be found on your machine.
DO NOT - E-mail me if you are unable to download disc images as I do not run those web sites and cannot help you.
NOTE - When directed to a multi-disc image on the Internet you should download all parts to be sure to have all discs in that image set.

Scan Disc Images

With this option enabled WinSTon will scan the disc images found on your machine and highlight those which it cannot find. As this process may take some time, particularly if you are scanning images on CD-ROM, you can disable this feature.

Hide Disc Images

WinSTon can be told to hide the names of any disc images which it cannot find on your system. As the favourites need to be scanned before they can be shown, the folders may take some time to appear.
NOTE - Favourites are only scanned once so to update the list you will need to restart the emulator.

Adding Folders


You can add 'folders' which can store disc images to the favourites list by highlighting a 'parent' folder and clicking on the 'Add Folder' button. This will allow you to enter a text name and a new folder will be created underneath the highlighted 'parent'.

Adding Disc Images


By highlighting a favourite folder you can use the 'Add Disc' button to add disc images to the favourite listings. The discs will be added to the 'folder' you highlighted. You can enter the text name of the disc image and also select which filenames to use for the floppy drives A and B. You may also select an alternative TOS image to use.

Editing Folders and Disc Images

You can choose the 'Edit' button to modify the settings for any highlighted 'folder' or 'disc image'.

Deleting Folders and Disc Images

The 'Delete' button will delete highlighted folders and disc images from the favourite listings. When deleting folders any sub-folders and disc images will also be deleted.
NOTE - Deleting items from the favourites listing cannot be un-done.
