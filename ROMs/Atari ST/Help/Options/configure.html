Configure

On this page you can alter the main configuration of the WinSTon emulator. There are also buttons to allow you to view help files for information on running the emulator and solving any problems you may come across.



Emulation Speed

When set to 'ST' speed, the emulator will run at the same speed as the original Atari ST - as long as your machine is fast enough. By sliding the bar over to the right you can increase the speed of the emulator which can be used to speed up loading or GEM based applications.
With this value set on 'Max' speed the emulator will run as fast as your machine will allow. It is important to note that when running in a faster emulation mode the sound will also play back faster than normal - infact all aspects of the emulator will increase accordingly.

Enable Sound

You can turn the Sound on or off by selecting this option. With the sound disabled the emulator will run faster.

Full Screen

If you have Direct X installed you can select this option to enter the full-screen display when you click OK on the dialog. Whenever you re-enter the options dialog this will be reset.

Quick Start/Trouble Shooting/Credits

By clicking on any of these buttons you can gain access to the appropriate pages in this Help file.
