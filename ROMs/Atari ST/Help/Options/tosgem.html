TOS/GEM

WinSTon can use a number of different versions of the Atari ST operating system(TOS). TOS is the Atari equivalent of DOS found on most PCs.
TOSes can be loaded into WinSTon in file form, although this version already comes with an emulated UK TOS 1.00 image built-in. You can override this with other territories or newer versions by simply selecting them. A number of TOS rom file images can be found on The Little Green Desktop.
Future versions will also allow you to enable accelerated/improved GEM performance but this is currently not implemented.



TOS Rom Image

You can enter the name of a TOS rom image file or select one using the Browse button. This image will then be used when the emulator is next reset. WinSTon is compatible will all versions of the ST TOS roms (1.00,1.02,1.04 and TOS 2.06). Rom versions 1.06 and 1.62 were designed for use only on the STe and as such will not run on a real STfm or WinSTon.
