Memory

You can change the amount of emulated memory WinSTon uses on this page of the dialog. You can also save the emulation 'state'. This saves out a 'snapshot' of the application/settings running so they can be re-loaded at a later time allowing you can continue where you left off. This effectively allows any game to be saved at any point, even when the game does not support a save function.



Memory Size

You can select between the four different standard sizes of ST Memory: 512Kb, 1Mb, 2Mb and 4Mb. The default setting is 1Mb. The changes will take effect after you reset the emulator.

Memory State Save

To take a 'snapshot' of the emulator click on the 'Save' button. If you have not selected a filename you will be presented with a dialog and on clicking OK the emulators state will be saved to your PC hard-drive. You can reload this snapshot of memory at any time and continue from where you left off. This option has been included so games can be saved at any point, even if they do not support a saving option.
It is important to note that a Memory State file is only compatible with the version of WinSTon that it was saved on. As a result you will not be able to load saved state files into newer releases of WinSTon.
NOTE - Saved state files can be very large in size, ranging from 1 to 4Mbytes.
