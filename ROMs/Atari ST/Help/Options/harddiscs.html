Hard Discs

WinSTon is able to view files on your PC hard-drive as if it were an ST drive. By default, the 'C' Drive is available for use but this can be modified through these options. A maximum of four emulated hard-drives can be configured, and each is mapped to a directory on your PC.

NOTE - Is is not recommended that you set these options to view your whole PC hard-drive as TOS has limits on the number of files it can store and exceeding this may cause problems with the emulator, as with a real machine. Similarly TOS does not support Windows long filenames so these will be shown as standard DOS 8.3 format.



Drive List

You can select up to four hard-drive partitions using this option. Each emulated drive is mapped to a directory on your PC. By default WinSTon will use a sub directory in the folder where it was installed and it is recommended that you keep this structure or create extra folders for the additional drives you create.

NOTE - When you select more than one hard-drive partition the additional drive icons on the Atari ST desktop will not be displayed - as with a real machine. You must use the desktop options and install the new drives to make the icons appear. Once you have done this you can save the desktop settings so they are restored next time you reset the emulator.

Boot from Hard Drive

As with a real ST, WinSTon will automatically scan for an '\AUTO' folder and accessory files on a floppy drive upon boot-up. Enabling this option will scan the first available hard-drive for these files and if no files can be found then the floppy disc is then checked.

Hard Disc Directories

If you have selected one or more emulated hard-drives you can cycle between them and set the directory on the PC where you wish to store any files. Enter the directory by either typing in a valid name or by using the 'Browse' button. These changes will take effect when the emulation is next reset.
