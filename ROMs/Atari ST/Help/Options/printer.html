Printer

You can print from WinSTon to your Windows printer or to a file. By printing to a file on your PC you can load the document into a number of Windows applications.

NOTE - Printer output from the emulator is limited to simple text-only documents as modern Windows printers differ so much from that of the ST. New printers can only be used through Windows printer drivers - few printers can now be used under plain DOS. WinSTon includes a 'print to file' option which can be used to 'print' to and then you can load this file into a Windows word-processor for re-formatting.



Enable Printing

You will need to select this option to turn on printing to a printer or file. If this option is disabled the emulator will behave as if no printer were connected.

Print To File

Printer output can be re-directed to a file using this option. The file can then be loaded into other applications. (Any printer control-codes or unknown characters will not be output)
You can select the file to print to by entering a valid filename in this dialog, or by using the 'Browse' button.
