Running a disc image

As you would insert a floppy disc into a real ST floppy drive, you do the same with WinSTons emulated drives. WinSTon uses floppy drive A and B. You can select files into each of these drives by clicking on one of the two Floppy Drive icons in the WinSTon tool bar. When a disc is inserted into a drive it will automatically reset the emulator and boot the image. If you do not which to reset the emulator simply click on the drop-down menu arrow to the right of the icon. From here you can select to insert the disc image without causing the reset.
Most disc images, especially games, auto-boot on a reset. If the disc does not boot you can view the disc from the Atari desktop just as you would with a real machine.
To eject discs from either drive you can click on the floppy disc icon and then choose the 'Eject' button from the select file dialog, or select 'Eject' from the drop-down menus. You can also create blank disc images from here.
You can also use the short-cut key to insert a disc without resetting. Simply hold down the SHIFT key when you click on one of a floppy disc icons.

Multiple Disc Images

As with a real ST you can eject and insert discs at any time. This allows you to insert different discs from a multiple disc set. These disc files usually end with the letters 'a', 'b', 'c'.... You can insert the correct disc when prompted by the program or some discs may change the screen colour when the disc is required - this method is exactly the same as on a real ST.
To prevent the emulator from resetting when inserting these disc images, select to insert the image from the drop-down menu, as described above.

The 'Automatically Insert Disc B' option found on the Disc Images settings page is on by default. When you insert a disc image into drive A, WinSTon will scan for the second disc in the series (by looking for a similar filename ending with the letter 'b') and insert this into the other drive.

Drag 'n' Drop

The Windows 'Drag n Drop' methods can also be used on WinSTon. You can drag a disc from Windows over onto WinSTon to insert the disc into drive A. To insert discs into drive B simply drag and then release while holding the mouse cursor over the drive B icon on the WinSTon tool bar.
