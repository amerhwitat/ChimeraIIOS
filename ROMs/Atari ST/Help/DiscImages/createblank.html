How do I create a blank disc image?

When saving game files you will need a blank disc image. You can create one by selecting the 'Create Blank Image' button on Disc Images dialog page. A file select dialog will appear giving you the chance to enter the filename of the disc image you wish to create - NOTE this operation will overwrite any disc image of the same name. Valid file extensions are .ST or .MSA. After choosing a filename the following dialog will open.
Due to inaccuracies in the emulation some games may not save to disc correctly - if this is the case then use the Memory State Save option to take a snapshot of the emulator.

Use the dialog controls to select the size and format of the image to create. If you wish to insert the disc into the floppy drive simply select the top most option. When you click on the 'Create' button the disc will be created and is pre-formatted ready for use.
