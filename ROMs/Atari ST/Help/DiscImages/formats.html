Supported disc formats

WinSTon supports a number of formats for disc images. The two main formats are '.ST' and '.MSA'.
ST format is simply a copy of each track/sector stored in a single file. The MSA format is a compressed version using Run-Length-Encoding. WinSTon will automatically detect which format the image is in and load it appropriately. You can save data back to a disc image as with a real disc.

You can also load .ZIP files into WinSTons floppy drives. Each ZIP file must contain just one .ST or .MSA disc image which is then extracted when you select the file.
