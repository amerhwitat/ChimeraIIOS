How can I create disc images?

There are a number of utilities that run on your PC which can read ST floppy discs inserted in the PCs drive and convert them to suitable disc image formats. One such utility is MakeDisk.
To use MakeDisk, simply exit Windows and return to DOS(Windows may prevent the disc from being read correctly). Insert the ST disc into the PC drive and at the DOS prompt enter:

MAKEDISK /READ image.st /AUTO

This will read the contents of the disc into the file 'image.st'. WinSTon can now load this image and run it. MakeDisk can also be used to write disc images back onto a floppy for use on a real ST.

NOTE - Original ST game discs cannot be made into disc images. These games use copy protection which is lost during the translation to a disc image file and will not run.
