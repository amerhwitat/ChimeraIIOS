How does it work?

WinSTon works by emulating the hardware of the STfm using software. By using code to emulate the 68000,MFP 68901,IKBD,ACIA 6850,WD 1772 FDC and the YM 2149 we can simulate a real ST using your PC.

The only requirement is the addition of a TOS Rom image to govern the operation of the emulator, and make it behave as an ST. This version has an emulated TOS rom built-in, but you can run other versions of the operating system if you wish. WinSTon reads disc images which are sector copies of floppy discs stored in single files. In addition you can also run files from your PC hard-drive through emulated drives.

WinSTon will only emulate the functionality of a standard STfm machine. Enhanced Atari machines, such as the STe and Falcon are not currently emulated.
