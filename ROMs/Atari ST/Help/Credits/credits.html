Credits

WinSTon is written by Paul Bates. This is a continuing project which was started a number of years ago in an attempt to run the game Paradroid '90. WinSTon was written using in a mix of Microsoft's C and assembler.

I would like to thank the following in helping to make WinSTon possible! (in no particular order):-

Tom Buck for running the Gravity web site and hosting the Medway Boys disc images.
Darren Birks for writing the disc utility MakeDisk and PC floppy disc access source code.
