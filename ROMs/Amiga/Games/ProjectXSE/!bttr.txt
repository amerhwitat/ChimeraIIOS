"Back to the Roots" is a documentation project attempting to 
index each and every software title ever released for the Amiga,
including info about the author, release year, screenshots etc.

Additionally we try and make the best of these files downloadable
whenever legally possible. We have grown a pretty massive 
archive so far, but there's still soooooo much to do :)

If you have good Amiga scene or software knowledge or a huge
collection of Amiga rarities and want to contribute, please 
consider helping us! <info@back2roots.org>
