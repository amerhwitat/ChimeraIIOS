## Publication rule

Not every Library artifact is suitable for direct publication. Before copying a file into an open-source repository, check:

- authorship and copyright;
- license compatibility;
- embedded third-party material;
- personal/private information;
- credentials and secrets;
- redistribution restrictions;
- whether the artifact is a research reference or original Chimera implementation.

When a file is not redistributable, publish a bibliographic/provenance entry and link to the lawful original source instead of copying it.
