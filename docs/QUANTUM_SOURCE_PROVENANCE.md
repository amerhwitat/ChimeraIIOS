# Quantum Source Provenance

Chimera II OS was informed by public quantum software projects but uses clean-room implementations. Qiskit, Cirq, PennyLane, NVIDIA CUDA-Q and cuQuantum are cited as integration/reference ecosystems; their code and licenses remain separate from Chimera code. Inspect each upstream LICENSE/header before redistribution, especially cuQuantum components whose repository documents mixed licensing.

Recommended adapter policy: pin versions, preserve source URLs, retain license notices, keep provider credentials outside the repository, and make external execution opt-in.
