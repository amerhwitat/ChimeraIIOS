# Chimera II Live CD

Firmware -> Spit Fire -> Jasper -> Koronos entry -> HAL -> storage/network/graphics -> Kore -> Aurora or text installer.

The Live CD carries the installer, command model, desktop, service manager and compatibility payloads. GRUB2/Multiboot2 is a compatibility fallback; foreign Linux/BSD/Darwin/Windows kernels are not linked into Koronos.
